# Arquivos de publicação

O ZIP `catalogo-publicacao.zip` é gerado por `scripts/gerar-publicacao.sh` (Linux/macOS) ou `scripts/gerar-publicacao.ps1` (Windows). Ele contém:

- a API publicada (`Catalogo.Api.dll` e dependências);
- os scripts do banco (`database/01_schema.sql`, `database/02_seed.sql`);
- o front compilado (`wwwroot/`);
- `LEIA-ME.txt` (como executar) e `ARQUIVOS.txt` (relação completa dos arquivos).
